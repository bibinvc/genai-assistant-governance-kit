# Fiche : écrire un bon prompt

Cinq éléments, dans cet ordre :

1. **Rôle** : « Tu es l'assistant de l'équipe achats. »
2. **Contexte** : à partir de quels documents, pour qui.
3. **Tâche** : un verbe précis : résumer, comparer, rédiger, classer.
4. **Format** : longueur, liste ou tableau, langue, ton.
5. **Contraintes** : ce qu'il ne faut pas faire, quoi répondre si l'information manque.

| Prompt faible | Prompt amélioré |
|---|---|
| Fais un mail au fournisseur. | Tu es acheteur. Rédige une réponse polie de 5 lignes au fournisseur qui annonce un retard de livraison. Demande la nouvelle date et le numéro de suivi. Ne promets aucune pénalité. |
| Résume ce document. | Résume cette procédure en 5 points pour un nouvel arrivant au quai. Garde les délais et les horaires exacts. Si un point n'est pas clair, signale-le au lieu de deviner. |
| C'est quoi la règle pour les litiges ? | À partir de la procédure litige fournisseur jointe, donne les étapes d'ouverture et les délais, avec la source. Si ce n'est pas dans le document, dis-le. |

Trois réflexes :
- Ne jamais coller de données personnelles, de mots de passe ou de documents confidentiels.
- Toujours relire : l'IA peut inventer avec assurance.
- Garder la décision : l'IA prépare, la personne valide.
