# Guide de maintenance pour le référent métier

**Mettre à jour une procédure** : remplacer le document dans l'assistant, puis repasser le tableau
de tests. Une procédure change, les réponses changent.

**Ajouter une question de test** : chaque fois qu'un utilisateur signale une mauvaise réponse,
l'ajouter au tableau avec la réponse attendue. Le jeu de tests grandit avec l'usage.

**Faire évoluer les instructions** : modifier une seule règle à la fois et repasser les tests.
Garder l'ancienne version des instructions pour revenir en arrière.

**Quand alerter l'équipe Digital Workplace** : réponse avec une donnée personnelle, réponse inventée
présentée comme sûre, demande d'usage sur des données C3 ou C4, nouvel usage RH ou sécurité.
