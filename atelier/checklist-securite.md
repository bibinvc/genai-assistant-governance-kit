# Checklist sécurité avant de partager un assistant ou un workflow

- [ ] L'outil est validé par la DSI pour ce type de données.
- [ ] Les documents ajoutés sont de niveau C1 Public ou C2 Interne uniquement.
- [ ] Aucune donnée personnelle ni secret dans les instructions ou les documents.
- [ ] Les utilisateurs voient clairement qu'ils échangent avec une IA.
- [ ] Les contenus envoyés à l'extérieur sont relus et validés par une personne.
- [ ] Le cas d'usage a été passé dans la grille AI Act (`python -m kit.cli screen`) ; s'il est
      « haut risque » ou « interdit », arrêt et échange avec juridique, DPO et sécurité.
- [ ] Un référent est nommé, avec une date de revue des tests.
- [ ] Les utilisateurs savent où signaler une réponse problématique.
